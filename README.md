## 搬瓦工是什麼？先確認它適不適合你

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的老牌 VPS 服務商，2004 年成立，在中文技術圈的名氣基本是靠用戶互相推薦傳開的。它賣的是自助管理的 KVM VPS：你租一台遠端伺服器，有完整 root 權限，裝系統、跑服務、建網站都自己說了算。

適合的人很明確：需要一台對大陸訪問速度友好的海外 VPS，並且願意（或願意學）基本的 Linux 操作。日常管理靠官方自研的 KiwiVM 面板，重裝系統、快照備份、切換機房這些都能在網頁上點幾下完成。

反過來，如果你想要的是帶 cPanel、幫你裝好 WordPress 的託管式主機，搬瓦工並不合適——它只負責把伺服器交給你，應用層的事全部自己來。這一點最好在下單前就想清楚。

## 線路差異：為什麼配置一樣，價差能到三倍以上

KVM 20G 和 CN2 GIA-E 20G 同樣是 2 核 1GB，一個年付 $49.99，一個季付就要 $49.99，差價全在線路上。

KVM 系列走普通國際線路，也就是俗稱的 163 骨幹網。白天問題不大，晚高峰碰上擁堵時丟包率有時能到 30% 以上，傳文件、開會議都會卡。CN2 GIA（AS4809）是中國電信最高等級的國際專線，直連且晚高峰基本穩定，代價是容量緊張、價格貴。搬瓦工在洛杉磯自營 8 條 10GbE 的 CN2 GIA 鏈路，這是它能立足這麼多年的核心本錢。

CN2 GIA-E 裡的「E」指 eCommerce，在 GIA 基礎上做了三網覆蓋：電信走 CN2 GIA，聯通走 AS9929，移動走 CMIN2。不管你家用的是電信、聯通還是移動，都能吃到優化線路，這也是它比老款 CN2 方案更值得推薦的原因。

還有一個能消除選擇焦慮的事實：機房買完可以免費換。CN2 GIA-E 套餐在 KiwiVM 後台能一鍵遷移到十幾個機房，資料保留，不用重新購買。先選洛杉磯，之後發現日本軟銀更快，隨時切過去就行。

3. **購物車頁可以填優惠碼。** 在 Promotional Code 輸入框填碼後點 Validate Code，價格有變化才算生效。目前多數時候沒有可用的常規碼，直接點 Checkout 即可（現狀見下一節）。
4. **結帳時一併註冊帳號。** 搬瓦工沒有單獨的註冊入口，註冊就發生在下單流程裡：老用戶在左側登入，新用戶在 New Customer 欄填郵箱、密碼和個人資料。兩個要點：郵箱必須真實，開通資料全靠它；國家、地址等如實填寫，並且**下單時不要掛代理或 VPN**——官方的欺詐檢測會核對 IP 所在地與填寫的國家，對不上訂單很可能被自動取消。
5. **確認帳單並付款。** 點 Complete Order 後會先生成一張未支付（Unpaid）帳單，核對金額後點 Pay Now，這才跳到支付網關。選支付寶的話，頁面會按當天匯率算出人民幣金額，手機掃碼或登入網頁版支付寶都能付；銀聯、PayPal、Visa/MasterCard 信用卡也都在支援列表裡。
6. **等開通郵件。** 付款成功後一兩分鐘，註冊郵箱會收到 IP 地址、root 密碼和 SSH 埠等資料，沒收到先翻垃圾郵件。也可以登入後台，在 Services → My Services 裡點 KiwiVM Control Panel 直接進管理面板。

## 下單前值得知道的幾條規則

有幾條只寫在條款和後台裡的規則，會直接影響使用體驗，購買前過一遍：

- **30 天退款。** 所有方案都帶，這是搬瓦工對新用戶最友好的一條。
- **流量用完不扣錢。** 超出月流量後 VPS 暫停到下個計費週期，不產生超額費用，不用擔心帳單爆炸。
- **遷移免費但有代價。** 換機房不收費、次數不限、資料保留，只會消耗一次等於硬碟容量的流量；遷移前建議先拍個快照墊底。
- **IP 被牆有補救。** 買到的 IP 恰好被封（概率不高）可申請檢測，確認後能更換。
- **備份機制。** KiwiVM 提供免費自動備份，另有最多 2 個永久快照，可下載到本地；重裝系統會清空硬碟，動手前先備份。
- **帳號安全。** KiwiVM 面板可開兩步驗證；root 密碼建議登入後立刻自己改掉，避免郵件洩露帶來的風險。

## 常見問題

**搬瓦工支持支付寶嗎？**
支持。支付寶是國內用戶最常用的方式，掃碼即可完成；銀聯、PayPal 和國際信用卡也都在支援列表裡，付款沒有障礙。

**買完之後怎麼管理？**
SSH 連上去操作，管理用瀏覽器打開 KiwiVM 面板就行，重裝系統、切機房、看流量統計都在裡面，不需要裝任何客戶端。前提是你會基本的 Linux 命令。

**可以退款嗎？**
可以，所有方案 30 天內可退，不滿意直接申請，這也是敢於先買再試的底氣。

**買搬瓦工需要先掛代理嗎？**
恰恰相反，下單時掛代理反而容易觸發欺詐檢測導致砍單。如果主網域打不開，那是 DNS 污染的問題，官方設有多個鏡像域名，換個網路環境或稍後再試即可。

**月付、季付、年付怎麼選？**
年付單價最低（CN2 GIA-E 年付相當於每季省約 $7.5），確定長期用就年付；不確定就季付起步，30 天退款對任何週期都適用。
